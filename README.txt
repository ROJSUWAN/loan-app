วิธีติดตั้งลงมือถือ (PWA)
1. อัปโหลดโฟลเดอร์นี้ทั้งหมดขึ้นเว็บโฮสต์ฟรี เช่น
   - Netlify Drop: https://app.netlify.com/drop  (ลากทั้งโฟลเดอร์ไปวาง ได้ลิงก์ทันที)
   - GitHub Pages: สร้าง repo → อัปโหลดไฟล์ → Settings > Pages > เลือก branch main
2. เปิดลิงก์ที่ได้ในมือถือ
   - Android (Chrome): เมนู ⋮ → "เพิ่มไปยังหน้าจอหลัก" / "ติดตั้งแอป"
   - iPhone (Safari): ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
3. เปิดจากไอคอนบนหน้าจอ ใช้ออฟไลน์ได้ ข้อมูลเก็บในเครื่อง

ทดสอบบนคอมก่อนได้: python3 -m http.server 8080  แล้วเปิด http://localhost:8080
